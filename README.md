# Currency Converter

Welcome to the **Currency Converter** project! This is a responsive React application that allows users to seamlessly convert values between different currencies using live exchange rates.

## 🎯 Purpose of the Project

The purpose of this project is to provide a clean, user-friendly interface for currency conversion. It demonstrates core React concepts including reusable components (`InputBox`), state management, handling complex component updates (like swapping currencies), and the use of custom hooks (`useCurrency`) to fetch and manage external API data.

## 🚀 Tech Stack

### Frontend
- **Framework:** React.js powered by Vite for a fast development experience.
- **Styling:** Tailwind CSS for a modern, responsive, and highly customizable UI.
- **State Management:** React Hooks (`useState`, `useId`) and custom hooks for business logic.
- **External API Integration:** Custom hook implementation to fetch real-time currency exchange rates.

## ⚙️ Installation & Setup Process

Follow these step-by-step instructions to get the project running on your local machine.

### Prerequisites
- Node.js (v16 or higher recommended)
- npm (Node Package Manager)

### 1. Clone the repository
```bash
git clone <your-repository-url>
cd currency-converter
```

### 2. Install Dependencies
Open your terminal inside the project directory and run:
```bash
npm install
```

### 3. Start the Development Server
Run the following command to start Vite's local development server:
```bash
npm run dev
```

### 4. Open the Application
Once the server is running, open your browser and navigate to `http://localhost:5173` (or the specific port provided in your terminal) to start converting currencies!
